## On framing precedent

You asked me to find the language that secured the existing Permission-via-Email
tables rather than invent framing. **That language is not in this repo.** I searched
for correspondence templates, outreach directories, and permission-request text across
all `.md`, `.qmd`, `.R` and `.txt` files: IRW records the *outcome* (a
`Derived_License` value of `Permission via Email` on 111 tables) but stores no record
of the request itself.

So `01_norc_gss_permission.md` is **not** modelled on a real precedent. It is grounded
in what the repo does establish about IRW's practice — the contribution workflow and
contact address in `contribute.qmd`, the per-table license/citation/source-link
provenance described in `docs.qmd`, and the data standard in `standard.qmd`. If the
actual precedent language exists in your email archive, prefer it over this draft.

One correction carried over: the count is **111** tables under Permission via Email
(106 exact-match plus 5 recorded in combination), not 106 as stated in the main report
body.
