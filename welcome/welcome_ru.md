# Item Response Warehouse (IRW; Хранилище данных об ответах на задания)

**Бесплатная, открытая коллекция унифицированных данных об ответах на задания для исследований в области психометрики и измерений.**

## Зачем существует IRW

Исследователям, изучающим измерения — в сфере образования, психологии и смежных областях, — нужны реальные данные для проверки и сравнения своих методов. Такие данные уже существуют в большом количестве. Но они разбросаны по множеству исследований, хранятся в самых разных форматах и зачастую с трудом поддаются повторному использованию из-за неясной документации или лицензирования.

Это хорошо известная проблема. Исследовательское сообщество сформулировало общий стандарт для её решения: данные должны быть **FAIR** — находимыми (Findable), доступными (Accessible), совместимыми (Interoperable) и пригодными для повторного использования (Reusable) (Wilkinson et al., 2016). Другие области воплотили эти принципы на практике, создав общие, стандартизированные ресурсы данных. В компьютерных науках коллекция размеченных изображений ImageNet дала исследователям общий ориентир и способствовала стремительному прогрессу в области искусственного интеллекта. Генетика и нейронауки создали похожие общие ресурсы для собственных данных.

Item Response Warehouse (IRW) применяет те же принципы FAIR к данным об ответах на задания. Он объединяет тысячи существующих наборов данных и преобразует их в единый общий формат — так что метод, проверенный на одном наборе данных, можно легко проверить на тысячах других.

## Что содержится в IRW

IRW содержит **тысячи наборов данных** («таблиц»), каждый из которых представляет собой коллекцию отдельных ответов. Ответ создаётся всякий раз, когда какой-либо человек (или иная единица) сталкивается с измерительным стимулом и результат фиксируется. Что именно считается стимулом, зависит от [семейства данных](/overview.qmd): задание, на которое отвечают по отдельности; другой участник, с которым сводит состязание; целый набор вариантов, которые нужно упорядочить; или профиль, собранный из случайно назначенных признаков. Примеры включают:

- Ответы учащихся на образовательные тесты и тесты способностей
- Пункты опросников, измеряющие личностные черты или установки
- Оценки, выставленные экспертами-людьми
- Игры, матчи и прямые сравнения, где два участника встречаются и один побеждает
- Бюллетени рейтингового голосования, ранжирования жюри и вопросы на упорядочивание в опросах
- Конджойнт-эксперименты, где респонденты выбирают между случайно собранными профилями
- Любые другие ситуации, где присутствуют повторяющиеся ответы на набор измерительных стимулов

Каждый набор данных в IRW спроектирован так, чтобы быть:

- **Находимым (Findable).** К каждому набору данных прилагаются заранее рассчитанные метаданные — число участников, число заданий, плотность ответов, предметная область и другие описательные теги, — чтобы наборы данных можно было находить и фильтровать без предварительной загрузки.
- **Доступным (Accessible).** Каждый набор данных можно получить через веб-браузер или пакет `irw`, используя бесплатную учётную запись.
- **Совместимым (Interoperable).** Каждый набор данных преобразован в длинный формат, по одной строке на ответ, в соответствии со стандартом своего семейства (описан ниже), поэтому один и тот же код анализа можно применять к множеству наборов данных с минимальными изменениями или вовсе без них.
- **Пригодным для повторного использования (Reusable).** Каждый набор данных имеет открытую лицензию, его происхождение документировано, а код, использованный для преобразования в формат IRW, доступен публично.

Наборы данных сильно различаются по объёму (от нескольких сотен ответов до нескольких миллионов) и по типу ответа (задания «да/нет», многокатегориальные оценки, баллы за частичное выполнение, неупорядоченные категории, исходы состязаний, места в ранжировке и другое).

## Стандарт данных

Каждая таблица IRW имеет **длинный формат**: по одной строке на ответ. Что *именно* представляет собой строка, зависит от семейства, к которому относится таблица, и то же самое касается столбцов, которые её несут.

| Core | `"core"` | [Core](/standard.qmd) |

| Competitions | `"comp"` | [Competitions](/comps_standard.qmd) |

| Simulated and synthetic | `"sim"` | [Simsyn](/simsyn.qmd) |

Simsyn нет на схеме: это семейство определяется происхождением данных, а не их формой, поэтому смоделированная таблица может иметь любую из этих форм. Столбцы каждого семейства приведены в [обзоре стандартов](/overview.qmd).


## Как это использовать

Есть три способа получить данные IRW — в зависимости от того, насколько высокую степень автоматизации вы хотите.

**1. Просмотр в веб-браузере**
Изучайте наборы данных и их метаданные прямо в [браузере данных IRW](/data.qmd) — учётная запись не требуется. Для скачивания полного набора данных требуется бесплатная учётная запись [Redivis](https://redivis.com), поскольку именно эта платформа размещает исходные данные.

**2. Использование пакета `irw` (рекомендуется)**
Пакет `irw` доступен как для **R**, так и для **Python**.

```r
# R
install.packages("irw")
library(irw)

irw_info()                     # overview of the IRW
irw_list_tables()              # list all available tables
irw_filter(var = "rt")         # find tables that include response times
df <- irw_fetch("4thgrade_math_sirt")   # download one table

# Other families are the same call with a source: comp, nom, conj, rank, sim
g <- irw_fetch("lichess_2013_blitz", source = "comp")
```

```python
# Python
# pip install irw
import irw

irw.info()
irw.list_tables()
irw.filter(var="rt")
df = irw.fetch("4thgrade_math_sirt")

# Other families are the same call with a source: comp, nom, conj, rank, sim
g = irw.fetch("lichess_2013_blitz", source="comp")
```

При первом использовании пакета вам будет предложено войти с помощью бесплатной учётной записи Redivis.

**3. Прямое использование клиентских библиотек Redivis**
Для рабочих процессов более низкого уровня или вне R/Python данные также можно получить через собственные клиентские библиотеки Redivis для R и Python. Подробности см. в [руководстве по началу работы](/getstarted.qmd).

### Не только скачивание данных

Проект IRW также включает:

- Постоянно растущий набор **[иллюстративных разборов (vignettes)](/vignettes/index.qmd)** — подробные примеры применения классических и новых методов измерения сразу на многих наборах данных IRW
- **Учебные материалы и наборы упражнений** для преподавания психометрики на реальных данных
- **Процесс подачи данных** для исследователей, желающих добавить собственные наборы данных в хранилище
