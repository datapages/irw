Item Text

ImportantAbout these data

IRW item text is reconstructed from published articles, codebooks, and supplementary materials using a largely automated pipeline with partial human review. It is provided for research purposes only. We make no guarantee that the text is accurate, complete, or correctly aligned with the item identifiers in the corresponding IRW response data; the original source document is always authoritative. Users are responsible for verifying item text against that source before drawing substantive conclusions. See Known Issues for documented discrepancies, and please get in touch if you find others.

Note also that the licenses recorded for IRW response data do not extend to the instruments themselves. Inclusion of item text here implies no license to reuse an instrument; copyright and related rights remain with the original rights holders, and users are responsible for obtaining any permissions their intended use requires.

Warningflorida_twins_friends

Items friends20/friends21 are not documented in the Florida Twin Project’s Wave 1 Child Survey Measures codebook; the other 19 items match exactly

Warningaddy_2021_sdq_ghana

SDQ_7’s response options run in reverse order in the source codebook (0=certainly true … 2=not true) relative to the other 9 items; transcribed as given, so this item may need reverse-coding

Warningaguirre_camacho_2021_shai

Item text is the English SHAI-18 original, but the study administered a Spanish translation whose wording the paper never quotes. The instrument has no item stems – each item is a group of four statements – so all text sits in option_text and item_text is empty. The 14/4 split between the two subscales is confirmed against the paper’s subscale statistics, but item order within each subscale rests on HAnx<N> being the instrument’s item N

Warningaguirre_camacho_2021_champion

Item text is the administered Spanish wording, but the 1/5 scale anchors are recorded in English because the source labels only the endpoints and only in English; the middle three points are unlabeled

Warningabdullah_2024_bsq_sevgen

The source papers state per-item scale ranges that do not match the data: items 3/4/6 are documented 1-5 but only reach 4, and item 7 is documented 1-7 but shows 1-4 plus 6-7. SEVG2 is published in the instrument but absent from the table

Warningajaykumar_2023_nasa_tlx

Item text is the official NASA-TLX rating-scale definitions, not the study’s own wording: the study administered a modified NASA-TLX on a 5-point scale and never published what participants saw, so the exact phrasing differs. The paper’s own analyses use three of these six items

Warningalexander_2017_dsi

Covers only the Differentiation of Self Inventory’s Emotional Reactivity and Emotional Cutoff subscales (23 of the 43 items). The dsi_1..dsi_23 to original-item mapping is reconstructed from the published appendix order rather than documented in the source, though it matches both the published subscale key and the response data

Warningalgner2022_cse

Item text is the English CSES original; the study administered a German translation whose exact wording could not be located

Warningalcoholhealthwarninglabel_brennan_2022_awareness_harms_followup

resp (0/1) is a derived binary rather than the original response scale: the study collapsed a 7-point agree/disagree item into aware/not-aware, so option_text records that rule rather than a literal option label

Warningdumas_organisciak_2022

Paper describes originality coded on a 0-4 scale; the IRW table is on 1-5. Whether this is an intentional shift during processing or an unverified discrepancy is unresolved

Warning16_personalityfactors

The source’s own instructions describe the scale as “(1) disagree … (5) agree” while its per-item codebook labels it “strongly disagree … strongly agree”; option_text follows the codebook. Item 163 is the one column the codebook omits, so its text comes from the IPIP scale listing rather than the dataset’s own documentation

Warningalgner2022_uwes

Both the UWES-9 instrument and this paper describe the response scale as 0-6 (Nie … Immer), but the study’s own data records the same seven categories as 1-7, so a response of 1 here corresponds to the instrument’s 0 (Nie). Item text is Schaufeli & Bakker’s official German UWES-9, while the paper cites a different German version (Sautier et al. 2015) whose wording was not obtainable

Warningalmuqbil_2022_epds

Participants completed the Arabic EPDS translation (Ghubash et al. 1997); the item text here is the English wording used to label the items in the study’s own data file, so it is not what respondents read

Warningalkouri_2025_icu_stressors

The source questionnaire changes the wording of its second response option partway through the scale – items 01-14 offer “Barely” and items 15-29 offer “Rarely” for the same value 2 – so option text varies by item; transcribed as the source gives it

Warningalsuhibani_2022_loc

The paper’s Methods describes this as a five-point scale, but the live data and the study’s own SPSS file both show a genuine 6-point “Strongly disagree” … “Strongly agree” scale; the data file was followed rather than the paper text

Warningalves_2017_hamd17

Item text follows a canonical reproduction of Hamilton’s original (1960) HDRS-17, which scores item 9 (Agitation) 0-2, but this study’s data scores it 0-4 – so HamD9Baixa responses of 3 and 4 have no option label. Item text is also a canonical reproduction rather than the study’s own materials, and item-to-text alignment follows the instrument’s standard order rather than an explicit map

Warningaltahla_2024_whoqol

Participants were Chinese adults who completed a Chinese-language version; the item text here is the English wording used to label the items in the study’s own data file, so it is not what respondents read

Warningaltahla_2024_whoqol_bref

Participants were Chinese adults who completed a Chinese-language version; the item text here is the English wording used to label the items in the study’s own data file, so it is not what respondents read. This table is also the spinal-cord-injury subsample of altahla_2024_whoqol, whose responses it duplicates

Warningaltahla_2024_swls

Participants were Chinese adults who completed a Chinese-language version; the item text here is the English wording used to label the items in the study’s own data file, so it is not what respondents read

Warningamarilla_2020_lawton_brody

resp (0/1) is the Lawton-Brody dependency score rather than the administered response: each domain offers 3-5 instrument levels that collapse to able/unable, so option_text names the scored category and lists the levels sharing it instead of a single literal option label. The study’s data supplement also records only the total IADL score, so the item-to-domain mapping follows the standard Lawton & Brody (1969) ordering rather than an explicit map, and item text comes from the canonical instrument

Warningamerican_multiracial_face

Each item is one photograph rated on one attribute, and the item codes are arbitrary integers assigned when the study’s 19 separate rating files were stacked – they carry no meaning and must not be read as an item order. item_text is therefore a constructed description of the stimulus rather than transcribed text; the verbatim rating question is the section_prompt. The AMFD PhotoID named in item_text is not stated in the source materials and was recovered by matching per-face rating means against the published norming table, and 9 faces (171 items) were never released in the AMFD and so carry no PhotoID. Only scale points 1 and 7 were labelled in the original survey, so option_text is blank for 2-6. Separately, the table has no Black-prototypicality ratings for the smiling photographs: the source repository provides them, but the IRW processing script does not read that file
